# 激光设备销售作战台（佛山·东莞）

伟卓 WZ 系列激光切管/坡口设备的销售辅助工具：客户库、跟进提醒、销售漏斗、拜访/报价/复盘、可编辑话术手册、设备型号匹配、回本计算器、KPI。

- 在线使用：https://lieshizhubi-cmyk.github.io/laser-sales-app/
- 手机打开后可“添加到主屏幕”，离线可用。
- 数据只保存在你自己的浏览器里（localStorage），请在「更多 → 数据与备份」定期备份。
- 内置的客户和机型均为虚构的「示例」数据，可一键清除。本应用不会联系任何客户。

图标以 base64 文本保存在 `icons-src/`，由 `.github/workflows/pages.yml` 在部署时解码为 PNG。
